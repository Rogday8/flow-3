# Гербарий №7 — цветочная мастерская

Третий концепт сайта цветочного магазина. Vite + React 19 + TypeScript + Tailwind CSS 4 + Motion + Lenis.

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Концепция

Ботанический архив: пергамент и миллиметровка, сургуч, латинские названия, музейные этикетки,
шрифты Prata, IBM Plex Mono, Golos Text и рукописный Marck Script. Не похож ни на тёмную
Maison Pétale (flow_1), ни на яркое «ПОЛЕ» (flow_2).

## Что на странице

- **Заставка** — кожаная обложка гербария открывается, внутри засушенный анемон.
- **3D-карусель образцов** на первом экране — крутится сама, тянется мышью или пальцем; под ней музейная этикетка.
- **Атлас** из 20 цветов с фильтрами; по клику — карточка образца с **лупой**, шкалами стойкости и покупкой поштучно.
- **Язык цветов** — выбираете чувства («люблю», «прости», «скучаю»…), сайт собирает букет-послание и печатает письмо, как на машинке.
- **Вечный букет** — на прокрутке цветок прижимается прессом, выцветает, получает штамп и раму.
- **Альбом композиций** — страницы перелистываются в 3D.
- **Открытка** — лицо и оборот с маркой, переворачивается, текст и адресат вводятся вживую.
- **Карта доставки** — гравюра с кольцами зон, курьер едет по маршруту к выбранной зоне.
- **Отзывы-письма** — конверты с сургучом открываются при наведении.
- **Корзина-конверт** — при заказе запечатывается сургучной печатью.

Корзина хранится в localStorage; формы демонстрационные. Адрес, телефон, отзывы — заглушки.
